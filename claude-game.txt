  pushing the player around.

  manipulated more easily than heavy ones.                                      
  2. Physics test objects                                                       
  Create several reusable objects with visibly different physical properties:   
                                                                                
  * Wooden crate: A standard rigid-body box that can be picked up, stacked,     
  rotated and thrown.                                                           
  * Rubber ball: A sphere with high restitution that bounces convincingly when  
  dropped or thrown.                                                            
  * Heavy metal box: A heavier object that is harder to move and produces more  
  substantial impacts.                                                          
  * Lightweight cardboard box: A light object that is easy to carry and throw.  
  * Cylinder: A physics object that can roll, tip over and be balanced.         
                                                                                
  Use straightforward, recognisable materials and visually distinguish the      
  objects.                                                                      
  Configure their mass, friction, damping and bounce properties appropriately.  
  3. Physics playground                                                         
  Create a simple test environment containing:                                  
                                                                                
  * A flat floor.                                                               
  * Several physics objects.                                                    
  * A sturdy table for stacking and placing objects.                            
  * A raised platform for dropping objects from a height.                       
  * A wall for throwing objects against.                                        
  * Enough open space to experiment with object manipulation.                   
                                                                                
  The environment should remain simple. This is a physics and interaction       
  prototype, not a full game level.                                             
  4. Rotation and placement                                                     
  Ensure objects can be positioned precisely.                                   
                                                                                
  * Support rotation around all three axes.                                     
  * Allow fine adjustments while holding an object.                             
  * Preserve the object's orientation when dropped.                             
  * Allow objects to rest naturally on tables, floors and other objects.        
  * Support stacking boxes and balancing objects.                               
  * Avoid automatically snapping objects to an artificial grid.                 
                                                                                
  5. Technical requirements                                                     
  Use Godot's native 3D physics systems, including RigidBody3D,                 
  CollisionShape3D and PhysicsMaterial where appropriate.                       
  Keep the manipulation system reusable so it can later work with furniture,    
  tools, destructible voxel objects and construction materials.                 
  Do not implement voxel destruction or construction yet. Leave the installed   
  add-on intact.                                                                
  Avoid changing unrelated systems.                                             
  6. Testing                                                                    
  Test the actual project and verify that:

  * Scrolling adjusts holding distance.

  * The rubber ball bounces.                                                    
  * Heavy and light objects behave differently.                                 
  * Objects collide correctly while held.                                       
  * Boxes can be stacked.                                                       
  * Existing FPS controls still work.                                           
  * The project loads without errors.

  reliable, satisfying object manipulation system for a future                  
  Taskmaster-inspired immersive sim.

  architecture over additional features.
